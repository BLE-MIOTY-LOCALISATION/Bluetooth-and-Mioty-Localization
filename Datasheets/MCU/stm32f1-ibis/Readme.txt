===============================
IBIS files for STM32F1 devices:
===============================

The package contains :


   + IBIS Files for stm32f101 devices on different packages :

	  o LQFP48
          o LQFP64
          o VFQFPN36
          o LQFP100

   + IBIS Files for stm32f103 devices on different packages :

	  o LQFP48
          o LQFP64
          o VFQFPN36
          o BGA100
          o LQFP100
